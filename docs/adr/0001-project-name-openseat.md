# 0001. プロジェクト名を OpenSeat とする

- **状態**: Accepted
- **日付**: 2026-09-16
- **関連**: 開発プラン 4.8

## 背景

名称を確定しないとリポジトリもドメインもパッケージ名も押さえられない。商標・ドメイン・パッケージレジストリ・GitHub・アプリストア・ソーシャルの重複を確認した。

## 選択肢

| 案 | 利点 | 欠点 |
|---|---|---|
| OpenSeat を継続 | 日本国内はクリア。`.jp` 系と主要なパッケージ名がすべて空き。既に計画書とメモで使用 | 主要な gTLD と GitHub 組織名と X のハンドルが埋まっている。同名のリポジトリが 96 件あり検索で埋没する。日本語では座席の種類を指す普通の語として通じる |
| SeatNavi など別名へ改名 | すべての名前空間が空いている | **商標を確認できていない**（調査の終盤で商標データベースへ到達できなくなった） |

## 決定

**OpenSeat を継続する。**

## 理由

- 日本国内に商標の登録も出願もなく、同名の法人もない。`openseat.jp` / `openseat.co.jp` / `open-seat.jp` はすべて空いており、npm・PyPI・crates.io・Docker Hub も空き。
- 個人開発で日本を主戦場にする以上、日本がクリアであることが実質的な判断材料のすべてになる。
- 代替候補はいずれも商標を確認できていない。**日本での商標クリアランスを実際に取れているのは OpenSeat だけ**であり、確認済みの名前を未確認の名前に替える合理性がない。

## 結果

- リポジトリは `kusui26/OpenSeat`。GitHub 組織の `openseat` は 2014 年作成の別プロジェクトが保有しており取得できないが、リポジトリ名は所有者ごとに一意であればよいので支障はない。
- 英語圏での検索上の地位と、国際展開での名称は、この名前では取れない。国内で完結する限り実害はないと判断して受容する。
- 提案資料には「OpenTable 社とは無関係」と明記し、ロゴで出所を差別化する。
- **見直しの条件**: トルコの出願 2026-087570（第 9・35・42・43 類、異議期間 2026-11-12 まで）が公告され、権利者が同種サービスで日本への出願に動いた場合。
